# Third-party software and assets

This repository does not vendor third-party Python packages, fonts, or binary
artwork. The built-in Discord artwork is generated by
`tools/assets/bin/roaring-presence-art.py` from geometric primitives; it does
not download or embed third-party or trademarked artwork. The generator may
use fonts already installed on the host system, but this repository does not
redistribute those font files.

The application invokes or optionally imports software supplied by the host
system. Those projects retain their own licenses; the MIT license in this
repository does not relicense them. Relevant dependencies include:

- Python (standard library)
- mpv, with CDDA support, for audio-CD playback
- psutil for reliable playback/process discovery
- PyQt6 and QtDBus for the optional graphical player and MPRIS integration
- Pillow for optional artwork-generation tools
- systemd, udev, and a compatible desktop/session D-Bus environment
- Discord-compatible desktop clients for the optional Rich Presence feature

Install these dependencies through your distribution's package manager and
review their package metadata for the applicable licenses. See
[Linux installation](docs/linux-installation.md) for package names and feature
requirements.
